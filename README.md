# soobinlim.com

Personal site — static HTML/CSS, no build step.

| File | |
|---|---|
| `index.html` | about / landing |
| `research.html` | research projects (click-to-expand `<details>`) |
| `notes.html` | notes |
| `style.css` | all styles (Newsreader / IBM Plex Sans / IBM Plex Mono via Google Fonts) |
| `script.js` | opens a research project from a `#anchor`, e.g. `research.html#tinoco` |
| `Soobin_Lim_CV.pdf` | CV, linked from every page |

Deploy: serve the directory as-is. Locally, `python3 -m http.server` from this folder.
